# Conduit Vision

## Mission

Conduit is an agentic workflow companion that helps humans keep pace with AI-assisted development.

## The Problem

The human-AI gap is widening:

| Human Reality | AI Reality |
|---------------|------------|
| Reads ~200 WPM | Outputs ~4000 tokens/min |
| Context: 7±2 items | Context: 200k tokens |
| Needs breaks, sleep | Runs 24/7 |
| Linear attention | Parallel execution |

**Whiplash**: AI moves faster than humans can absorb. You approve a plan, 30 seconds later there's 500 lines across 12 files.

**Burnout**: Trying to keep up. Reviewing AI output is exhausting. The human becomes a rubber-stamp machine.

**Lost ownership**: "I don't know how my own codebase works anymore."

## The Solution

Conduit doesn't slow down the machine. It speeds up the human.

- **Observe** without interrupting
- **Navigate** without losing context
- **Catch up** with AI-generated summaries
- **Focus** when you need depth
- **Capture** insights as they come

## Core Principles

| Principle | Meaning |
|-----------|---------|
| **Thin Veil** | Observe everything, interrupt nothing. Never block the agent loop. |
| **Human Amplifier** | Speed up humans, don't slow down machines. |
| **AI Summarizes AI** | Use headless Claude to generate digestible insights. |
| **Context is King** | The hardest problem is "where was I?" - solve it ruthlessly. |
| **Capture > Remember** | Externalize mental state. Notes, threads, checkpoints. |

## What Conduit Is NOT

- Not a gatekeeper or approval system
- Not a code review tool
- Not an agent orchestrator
- Not intrusive or interruptive

## Target User

Developers working with multiple AI coding agents (Claude, Cursor, Aider, Copilot) across multiple projects who need to:

- Stay aware of what agents are doing
- Switch contexts without losing their place
- Capture insights and notes quickly
- Enter deep work when needed
- Understand what happened while away
