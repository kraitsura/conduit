# Conduit Features

## Overview

Features organized by function. Each category serves a specific human need.

---

## OBSERVE - Passive Awareness

*What's happening across all my projects?*

| Feature | Command | Description |
|---------|---------|-------------|
| Status | `conduit status` | Context-aware status display |
| Live Feed | `conduit feed` | Real-time activity stream |
| Agents | `conduit agents` | List active AI agents |
| Health | `conduit health` | Per-project health indicators |
| Watch | `conduit watch` | Persistent live mode with notifications |

---

## NAVIGATE - Context Switching

*Jump between projects without losing your place.*

| Feature | Command | Description |
|---------|---------|-------------|
| Switch | `conduit switch <project>` | Switch with full context restoration |
| Dashboard | `conduit dashboard` | Birds-eye view of all projects |
| Threads | `conduit threads` | Named work streams |
| Workspaces | `conduit workspace <name>` | Group related projects |

---

## CATCH-UP - AI Summaries

*What happened while I was away?*

| Feature | Command | Description |
|---------|---------|-------------|
| Recap | `conduit recap` | AI summary since last interaction |
| Digest | `conduit digest` | Daily/weekly summaries |
| Next | `conduit next` | Prioritized attention queue |
| Blocked | `conduit blocked` | Agents waiting on human |
| Replay | `conduit replay <session>` | Step through agent decisions |
| Semantic Diff | `conduit diff <range>` | Behavior-focused diff analysis |
